# Онлайн-магазин подарков

Учебный проект по дисциплине «Проектный практикум».

## Описание

Приложение представляет собой простой онлайн-магазин подарков.
Пользователь может просматривать каталог товаров, искать товары,
открывать карточку товара, добавлять товары в корзину и просматривать
информацию о магазине на странице «О нас».

## Стек технологий

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite
- GitHub
- WEEEK
