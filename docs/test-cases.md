# Чек-лист тестирования GiftShop

## Спринт 1

### Главная страница

- [ ] Главная страница открывается без ошибок.
- [ ] Отображается шапка сайта.
- [ ] Отображается навигация.
- [ ] Отображается блок каталога.
- [ ] Поле поиска отображается.
- [ ] Карточки товаров отображаются корректно.
- [ ] Ссылка на страницу «О нас» работает.
- [ ] Ссылка на корзину работает.

### Страница «О нас»

- [ ] Страница «О нас» открывается.

- [ ] Сервер запускается без ошибок.
- [ ] Маршрут `/api/health` возвращает статус.
- [ ] Маршрут `/api/products` возвращает список товаров.
- [ ] Маршрут `/api/products/1` возвращает один товар.
